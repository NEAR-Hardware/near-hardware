# Testing an Integration

> Test an integration on NEAR testnet or in a local sandbox.

Use testnet to exercise deposit detection, withdrawal submission, and reconciliation before enabling mainnet operations.

> [!TIP]
>
> Testnet tokens are free to use and can be easily obtained from the [testnet faucet](https://docs.near.org/getting-started/faucet.md).

***

## Testnet Setup

Generate test accounts using the [Accounts](https://docs.near.org/integrations/accounts.md) examples and fund them through the [testnet faucet](https://docs.near.org/getting-started/faucet.md). The faucet page also links to a faucet for testnet fungible tokens.

* RPC endpoints:
  * `https://rpc.testnet.near.org`
  * `https://test.rpc.fastnear.com`
  * [More Testnet RPC providers](https://docs.near.org/api/rpc/providers.md#testnet)
* Explorer: [Testnet NearBlocks](https://testnet.nearblocks.io/)
* Node and archival access: [Nodes](https://docs.near.org/integrations/nodes.md)

***

## Local Sandbox Testing

For local development and automated tests, a sandbox is also an option. It runs a local NEAR network where you can create test accounts, deploy contracts, and test transfers in a controlled environment. See [sandbox tests](https://docs.near.org/smart-contracts/testing/integration-test.md) for setup and examples.
